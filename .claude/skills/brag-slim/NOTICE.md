# Provenance

Vendored from [`latent-spaces/brag`](https://github.com/latent-spaces/brag)
(`skills/brag-slim/SKILL.md`), commit `c893c5ed52aed84e3e2ee56787de869fccdae6b0`.

`/brag-slim` builds a short launch video for this project itself — story,
visuals, audio, and render — using tools already available on the machine
(no bundled assets, no external rendering service). The upstream repo also
ships a heavier `/brag` skill built on the external Hyperframes service
plus ~17MB of bundled music/SFX; it was left out here to keep this repo
free of unrelated binary assets and an external service dependency. Ask to
add it too if you'd rather use that version.

To update: re-copy `skills/brag-slim/SKILL.md` from the upstream repo.
